# راه‌اندازی فید بومی اندروید و اتصال امن فیسبوک

مسیر عمومی فید: `GET https://jametulhoda.vercel.app/api/mobile-feed`

این مسیر JSON فقط‌خواندنی برای اپلیکیشن بومی است. محتوای سایت فقط از رکوردهای منتشرشده خوانده می‌شود. در صورت نبود تنظیمات Meta، فید محتوای سایت را همچنان تحویل می‌دهد.

## تنظیم متغیرهای محیطی Vercel

در **Vercel → پروژهٔ وب‌سایت `jametulhoda` → Settings → Environment Variables** این متغیرها را اضافه کنید، سپس Production را دوباره Deploy کنید:

| نام | مقدار |
|---|---|
| `META_PAGE_ID` | شناسهٔ صفحهٔ رسمی مدرسه |
| `META_PAGE_ACCESS_TOKEN` | توکن Page Access Token با مجوزهای لازم برای خواندن پست‌های صفحه |
| `META_PAGE_URL` | نشانی HTTPS صفحهٔ رسمی، مثل `https://www.facebook.com/...` |
| `META_PAGE_NAME` | نام نمایشی صفحه، مثل `مدرسه جامعه‌الهدی` |
| `META_GRAPH_API_VERSION` | اختیاری؛ در صورت نیاز برای پین‌کردن نسخهٔ پشتیبانی‌شدهٔ Graph API |

**توکن را در Android، GitHub، کد PHP یا پاسخ JSON قرار ندهید.** این توکن فقط در متغیر محیطی Production سرور نگهداری می‌شود. اگر آن را قبلاً در پیام عمومی، مخزن یا فایل APK گذاشته‌اید، آن را از Meta باطل و توکن تازه‌ای بسازید.

## مراحل Meta

1. در Meta for Developers یک برنامهٔ متعلق به مالک صفحه ایجاد/انتخاب کنید.
2. حساب مدیر صفحه را به برنامه وصل کنید و Page Access Token متناسب با صفحه بگیرید.
3. مجوزها و قابلیت‌های لازم برای خواندن پست‌های همان صفحه را مطابق وضعیت برنامه در داشبورد Meta فعال کنید. Meta ممکن است بر اساس نوع صفحه، دسترسی برنامه و سطح دسترسی، مجوز یا بررسی اضافه بخواهد.
4. متغیرهای بالا را در Vercel اضافه کنید و Deploy مجدد انجام دهید.
5. مسیر `/api/mobile-feed` را باز کنید. فیلدهای `meta.facebook_configured` و `meta.facebook_connected` باید وضعیت اتصال را گزارش کنند.

این یکپارچه‌سازی برای **پست‌های صفحه‌ای که مالک اختیار مدیریت آن را دارد** طراحی شده است؛ اسکرپینگ، دور زدن ورود، جمع‌آوری پیام خصوصی یا خواندن خوراک شخصی کاربران انجام نمی‌شود.

## عیب‌یابی

- `facebook_configured=false`: یکی از دو متغیر `META_PAGE_ID` یا `META_PAGE_ACCESS_TOKEN` تنظیم نشده است.
- `facebook_configured=true` و `facebook_connected=false`: شناسه، توکن، نسخهٔ Graph API یا مجوزهای صفحه را بررسی کنید. کد خطای Meta در لاگ سرور فقط به‌شکل محدود ثبت می‌شود تا توکن افشا نشود.
- `items=[]`: ممکن است هنوز محتوای منتشرشده‌ای در دیتابیس موجود نباشد یا اتصال دیتابیس آماده نباشد.
