# اسنپ‌شات‌های HTML (خروجی آزمون، نه ورودی ساخت)

فایل‌های این پوشه نسخهٔ ذخیره‌شدهٔ HTML هر صفحه‌اند که `tests/responsive-audit.mjs`
با متغیر `SNAPSHOT_DIR` تولید می‌کند؛ هدفشان این است که اندازه‌گیری چیدمان
(ارتفاع کارت، اسکرول افقی، تعداد ستون) بعداً **بدون PHP و دیتابیس** قابل تکرار باشد:

```sh
# ۱) یک بار با سرور زنده بگیر
SNAPSHOT_DIR=tests/snapshots TEST_BASE_URL=http://127.0.0.1:8080 node tests/responsive-audit.mjs

# ۲) بعداً روی همان فایل‌ها دوباره اندازه بگیر
JHD_PAGES='[["home","/tests/snapshots/home.html"]]' node tests/responsive-audit.mjs
```

> این‌ها artifact اند: اگر قالب عوض شد (مثلاً اسکلت هاب‌های صفحهٔ اصلی یا رجیستری
> ناوبری)، اسنپ‌شات **کهنه** است و باید دوباره گرفته شود. هیچ آزمونی با آن‌ها
> مقایسهٔ متن نمی‌کند؛ فقط منبع اندازه‌گیری‌اند. پس در بازبینی کد، تفاوت
> `home.html` با `index.php` را باگ نگیرید — اسنپ‌شات را به‌روز کنید.
